Como conectar o Feegow
  1. No Feegow, acesse Configurações → Integrações → API e copie o token de acesso.
  2. Cole a Base URL padrão (https://api.feegow.com/v1/api) e o token acima.
  3. Clique em Testar conexão antes de salvar — o status deve ficar verde.
  4. Ative a integração e use o link na bio para direcionar pacientes aos formulários Gestgo.

Dúvidas? Consulte a documentação oficial Feegow ou fale com nosso suporte pelo WhatsApp.
