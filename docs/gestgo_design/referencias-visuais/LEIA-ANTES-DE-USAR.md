# Capturas de referência — Gestgo

Estas imagens foram enviadas pelo proprietário e são exemplos pontuais das telas. **Não representam garantia de que a versão HEAD esteja idêntica.**

O pacote inclui somente as capturas de referência que não mostram identificadores evidentes de contas ou pacientes nas telas fornecidas. Capturas de login, dashboard, pessoas e protocolos com dados visíveis não foram incluídas. Se precisar dessas referências, capture novamente em homologação com dados sintéticos.

Leia `../especificacoes/25-refinamento-visual-premium.md` para o escopo, os riscos e as observações sobre cada tela.
